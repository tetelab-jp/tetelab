# standalone

サーバー不要・ブラウザだけで動く単体ツールを置くディレクトリ。
どのファイルもビルド不要で、HTMLを直接ブラウザで開けば動作する。

## hpb-keyword-filler.html — キーワード尺合わせ

HPB/サロンボードの入力欄で、本文を書いたあとに余った文字数を
SEOキーワードでぴったり埋めるためのツール。

### 使い方
1. `standalone/hpb-keyword-filler.html` をブラウザで開く（ダブルクリック可、`file://`でも動く）
2. キーワード帳にキーワードを一括登録する（改行・カンマ・読点区切り）
3. 入力欄のプリセットを選び、本文を貼り付ける
4. 「余りを自動で埋める」→ 余りがちょうど0になる組み合わせから順に候補が出る
5. 「これを使う」または「コピー」でサロンボードへ貼り付ける

### 仕様メモ
- 組み合わせ探索は部分和問題のDFS（枝刈り＋候補上限つき、探索ノード上限25万）。
  候補は「余りが少ない順 → 語数」で並べる。区切り文字も文字数に含めて計算する。
- 文字数の初期プリセットはサロンボードの実際の入力上限に合わせている
  （スタイル名30／メニュー内容50／スタイリストコメント120／ブログタイトル25／口コミ返信500）。
  根拠は `src/routes/style.tsx`・`src/routes/blog.tsx`・`src/lib/ai-generate.ts` および
  HANDOFF.md「文字数上限の不一致・入力順序の修正」の節。
- 全角2文字・半角1文字で数えるモードあり（バイト数換算の欄向け）。
- キーワード帳・設定は `localStorage`（キー `hpb-keyword-filler.v1`）に保存する。
  端末をまたぐ同期はしないため、控えは「書き出し」でテキストとして取る。
- 外部通信はGoogle Fontsの読み込みのみ。オフラインでも代替フォントで動作する。

### 動作確認
Playwright(Chromium)で確認済み：キーワード一括登録／プリセット切替／自動補完で
合計文字数が上限ちょうどになること／リロード後の復元／全角2文字モード／
区切りなしモード／ライト・ダーク両テーマ／モバイル幅で横スクロールが出ないこと。
